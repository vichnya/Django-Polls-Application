# Django Polls Application

Учебное веб-приложение на Django для создания опросов и проведения голосования.

## Цель

На практике изучить разработку веб-приложений на Django, работу с моделями и связями между ними, представлениями, шаблонами и административной панелью.

## Что реализовано

* страница со списком доступных опросов;
* просмотр отдельного опроса;
* голосование за выбранный вариант;
* отображение результатов голосования;
* модели `Question` и `Choice`;
* связь между моделями `Question` и `Choice` через `ForeignKey`;
* административная панель Django;
* создание и редактирование вопросов и вариантов ответов через админку;
* поиск и фильтрация вопросов в административной панели.

## Запуск

Установить зависимости:

```bash
pip install django django-debug-toolbar
```

Применить миграции:

```bash
python manage.py migrate
```

Запустить сервер:

```bash
python manage.py runserver
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000/
```
