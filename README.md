# Django Polls Application

Учебное веб-приложение на Django для создания опросов и проведения голосования.

## Цель

На практике изучить разработку веб-приложений на Django, работу с моделями и связями между ними, generic views, шаблонами и административной панелью.

## Что реализовано

* список доступных опросов;
* просмотр отдельного опроса;
* голосование за выбранный вариант;
* отображение результатов голосования;
* ограничение отображения будущих опросов;
* модели `Question` и `Choice`;
* связь `Question` и `Choice` через `ForeignKey`;
* административная панель Django;
* добавление вариантов ответа непосредственно из формы редактирования вопроса в админке;
* поиск и фильтрация вопросов в административной панели.

## Основные страницы

* **Список опросов** — отображает последние опубликованные вопросы.
* **Опрос** — позволяет выбрать вариант ответа.
* **Результаты** — показывает количество голосов за каждый вариант.
* **Админка** — позволяет создавать и редактировать вопросы и варианты ответов.

## Запуск

Установить зависимости:

```bash
pip install django django-debug-toolbar
```

Применить миграции:

```bash
python manage.py migrate
```

Запустить сервер:

```bash
python manage.py runserver
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000/
```
